実行コスト

既定の財布。free＝従量0のツールのみ（本人サブスク・ローカル実行）。paid_ok＝有料の frontier モデル/ツールも許可（コストは都度開示）。プラン生成のモデル経路もこれに連動します。

スケジューラ

cron / build-state イベントで自動化を発火します。

in-hub スケジューラ

ローカル実行（autorun）

hub がローカル agent を自プロセスで代理実行するか。OFF にすると専用 worker 起動時のみ実行（broker-only）。

グローバル autorun

モデル経路（routing）

プランの各ステップの宛先。cheap＝軽い処理（無料サブスク/ローカル）、strong＝重要処理（本人 Claude 等）。空欄＝既定。

プロバイダ詳細（ollama / openai / anthropic）

runner 側の既定 host/model（変更は hub 再起動で反映）。API キーはここでは設定できません（env / .dev.vars のみ）。

連携（MCP サーバー）

プランから使える外部ツール群。ON のサーバーのツールだけが解決対象になります。

オートメーション

保存済みフローの自動実行（スケジュール / build-state）。OFF で発火を即停止（削除はしません）。

テンプレート

同梱の定番フローをワンクリックで導入。導入後は編集可能なワークフローとして複製されます。

ゴール

長期の願い（例「3ヶ月でフォロワー1000」）を神龍に預け、手動チェックインで進捗を追います。

成果検証（自動チェック）

オートメーションの実行結果が期待どおりか自動判定し、外れたら通知します。assert=決定論（$0）・judge=AI が yes/no。

ドリフト検出

成果検証より上位の警告。同じオートメーションが3連続で失敗、または出力構造が急変したときに記録します（自動検出・読み取り専用）。

神龍の提案

神龍が自分の実行履歴を観察して「定期化できそう」「連続 fail 中」などを自動で提案します。外部受信箱は読みません。

クレデンシャル保管庫

フローが名前で参照する API キー / パスワードを安全に保存（macOS は Keychain）。値は二度と表示されません（在否のみ）。

通知（Webhook）

フロー実行の完了 / キャンセル時に Slack・Discord・任意の Webhook へ push 通知します。

環境・API キー

キーの在否のみ表示（値は出ません）。LLM はローカル claude -p（従量0）でも動きます。
